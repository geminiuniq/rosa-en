## 第 1 题 m1s1 ｜ Expand and simplify (3x − 2)(x + 5) − (x − 4)²　[3]

**标准答案**：2x² + 21x − 26

**学生作答**
```
= 3x² + 15x − 2x − 10 − (x² − 8x + 16)
= 3x² + 13x − 10 − x² + 8x − 16
= 2x² + 21x − 26
```

**对照 Mark Scheme**
- M1 (3x−2)(x+5) = 3x² + 13x − 10　✅
- M1 (x−4)² = x² − 8x + 16 并整体相减（括号变号正确）　✅
- A1 最终 2x² + 21x − 26　✅

**评分：3 / 3** ✅　减括号时每一项都正确变号，是最容易丢分的地方，处理得很好。

## 第 2 题 m1s2 ｜ 矩形 长 (2x+1) cm、宽 (x+3) cm，求展开形式的 (i) 面积 [2] (ii) 周长 [1]

**标准答案**：面积 2x² + 7x + 3；周长 6x + 8

**学生作答**
```
i)  (2x+1)(x+3) = 2x² + 6x + x + 3 = 2x² + 7x + 3
ii) 2[(x+3)+(2x+1)] = 2(3x+4) = 6x + 8
```

**对照 Mark Scheme**
- M1 面积 = (2x+1)(x+3)　✅
- A1 2x² + 7x + 3　✅
- A1 周长 = 2(3x+4) = 6x + 8　✅

**评分：3 / 3** ✅　面积、周长都写成题目要求的「展开形式」，完全到位。

## 第 3 题 m1s3 ｜ Given (x + p)(x + q) = x² + 7x + 12，p < q，求 p、q　[3]

**标准答案**：p = 3, q = 4

**学生作答**
```
x² + 7x + 12 = (x + 3)(x + 4)    （用网格/十字相乘法分解）
p = 3,  q = 4
```

**对照 Mark Scheme**
- M1 p + q = 7 且 pq = 12　✅（用因式分解网格等价地做到了）
- M1 找出相加为 7 的 12 的因数　✅
- A1 p = 3, q = 4（且满足 p < q）　✅

**评分：3 / 3** ✅　网格法分解正确，并注意了 p < q 的条件。
> 小建议（不扣分）：可补一句「比较系数得 p+q=7, pq=12」，在证明/推理类题目里会让逻辑更完整。

## 第 4 题 m1s4 ｜ Show that (2n + 1)² − (2n − 1)² = 8n for every integer n　[3]

**学生作答**
```
[(2n)² + 2(2n)(1) + 1²] − [(2n)² − 2(2n)(1) + 1²]
= (4n² + 4n + 1) − (4n² − 4n + 1)
= 4n² + 4n + 1 − 4n² + 4n − 1
= 4n + 4n
= 8n   (shown)
```

**对照 Mark Scheme**
- M1 (2n+1)² = 4n² + 4n + 1　✅
- M1 (2n−1)² = 4n² − 4n + 1 并相减　✅
- A1 = 8n（得证）　✅

**评分：3 / 3** ✅　完整用了平方展开公式，抵消项清楚，结尾写 (shown) 规范。
